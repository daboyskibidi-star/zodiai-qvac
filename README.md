<h2>✨ What is ZodiAI?</h2>



<p>

ZodiAI is a lightweight zodiac companion that calculates your zodiac sign from your birthday and uses local AI to generate a personalized zodiac reading.

</p>



<p>

Everything is powered by <strong>Tether QVAC</strong> and runs locally instead of relying on a cloud AI API.

</p>



<br>



<h2>🚀 Features</h2>



<ul>

&#x20; <li>🎂 Birthday-based zodiac detection</li>

&#x20; <li>♈ Zodiac sign and symbol</li>

&#x20; <li>🌍 Zodiac element information</li>

&#x20; <li>🤖 Personalized AI-generated reading</li>

&#x20; <li>🔒 Local on-device AI inference</li>

&#x20; <li>⚡ Simple and responsive interface</li>

<h2>📦 Installation</h2>



<p>Clone the repository:</p>



<pre>

git clone https://github.com/daboyskibidi-star/zodiai-qvac.git

cd zodiai-qvac

npm install

</pre>



<br>



<h2>▶️ Run ZodiAI</h2>



<p><strong>1. Start the local QVAC server:</strong></p>



<pre>node server.js</pre>



<p><strong>2. Open another terminal and start the frontend:</strong></p>



<pre>npm run dev</pre>



<p><strong>3. Open the app:</strong></p>



<pre>http://127.0.0.1:5173/</pre>



<p>

Enter your birthday and click <strong>Discover My Zodiac</strong> ✨

</p>



<br>



<h2>🧠 How It Works</h2>



<ol>

&#x20; <li>🎂 Enter a birthday.</li>

&#x20; <li>♈ ZodiAI calculates the zodiac sign locally.</li>

&#x20; <li>📡 The zodiac information is sent to the local server.</li>

&#x20; <li>⚡ QVAC loads the local AI model.</li>

&#x20; <li>🤖 <code>completion()</code> generates the reading.</li>

&#x20; <li>✨ The AI reading appears in the app.</li>

</ol>
